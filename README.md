# CrayonUtil 🖍️

[![Plugin Phase](https://img.shields.io/badge/Phase-In__Development-orange?style=for-the-badge)](https://github.com/)
[![Server Version](https://img.shields.io/badge/Minecraft-1.21.x-brightgreen?style=for-the-badge)](https://papermc.io)

**CrayonUtil** is the official core utility plugin for **CrayonSMP 3**. 

> ⚠️ **NOTE:** This project is currently in early **development**. Features and codebase are subject to change at any time.

---

## 🚀 Project Status & Concept

CrayonUtil is being built to handle background utilities and essential core functions for CrayonSMP Season 3. Since the project is in its prototyping stage, the final feature set is not yet locked in. 

---

## 💻 Tech Stack

* **Platform:** Paper (1.21.x)
* **Language:** Java

---

## 🛠️ Development Setup

To clone and build the plugin locally for testing:

1. Clone the repository:
   ```bash
   git clone [https://github.com/Qouve-Creations/CrayonUtil.git](https://github.com/Qouve-Creations/CrayonUtil.git)

    ```

2. Build the project using Maven:
    ```bash
    mvn clean package
    
    ```


3. Find the compiled `.jar` file in the newly created `bundle/target/` directory.
